# 🏁 Contributing to Ajith Kumar Racing (AK RACING)

Thank you for your interest in contributing to the **AK Racing** digital platform!

## Guidelines
1. **Fork the Repository:** Create your feature branch (`git checkout -b feat/ultra-aero`).
2. **Adhere to Code Standards:** Zero external bloated frameworks. Vanilla ES6+ modules and Three.js / Web Audio API.
3. **Run Unit Tests:** Always run `node tests/physics.test.js` and `node tests/audio.test.js` before submitting.
4. **Conventional Commits:** Use standard conventional commit format (`feat:`, `fix:`, `perf:`, `docs:`).

## Pull Request Process
- Ensure zero console errors.
- Test 60 FPS performance on both desktop and mobile devices.
