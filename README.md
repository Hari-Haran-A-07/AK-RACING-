## 🎮 Interactive Controls & Keyboard Shortcuts

| Control | Action |
| :--- | :--- |
| `W` / `Space` / `Up Arrow` | **Throttle / Accelerate** (Rev Engine & Fire Exhaust Flames) |
| `S` / `Down Arrow` | **Brake / Decelerate** (Glows Carbon-Ceramic Rotors) |
| `E` | **Paddle Shift UP** (Triggers Shift Backfire & Flame) |
| `Q` | **Paddle Shift DOWN** (Engine Braking) |
| `M` | **Toggle Movable Speedometer ON / OFF** (Drag Anywhere) |
| `N` | **Hybrid Overboost** (Cyan Plasma Flame Surge) |
| `L` | **Launch Control** (5,500 RPM Rev-Limit Hold & Dump) |
| `B` | **Burnout Mode** (Tire Smoke & Continuous Flames) |
| `I` | **Engine Start / Stop Ignition** |
| `Mouse Drag` | **Move Speedometer (when Move is ON) / Orbit Car 360° in 3D Viewport** |
| `Mouse Scroll` | **Zoom In / Out on 3D Car** |

## 🚀 How to Run Locally

```bash
# Option A: Using Node.js
npm start

# Option B: Using Python 3
python -m http.server 3000
```
Then open your browser and navigate to: **`http://localhost:3000`** (or simply double-click `index.html`).
