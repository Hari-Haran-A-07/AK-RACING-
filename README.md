# 🏎️ AJITH KUMAR RACING (AK RACING) — OFFICIAL HYPER-TELEMETRY & GT3 SHOWCASE

> **The $2 Billion Tier Next-Gen Motorsports Digital Platform**  
> Complete with interactive Fire Speedometer Automation, Real-time 3D GT3 Demo Race Car with active exhaust flame throwers, and Procedural Race Car Throttle Audio Synthesizer (Web Audio API).

---

## ⚡ Core Features & Innovations

### 1. 🔥 Fire Speedometer & Telemetry Automation
- **Hyper-Realistic Animated Fire Particle System:** Over 400 dynamic flame and spark particles dancing along the tachometer perimeter and speed needle tip.
- **Autopilot Dyno Run Mode:** Automatic 0 to 340+ km/h drag acceleration test shifting through gears 1 to 6 with roaring engine harmonics and explosive shift flames.
- **Auto Hot Lap Simulation:** Realistic cornering, apex throttle, heavy braking, and straight-line blasts inspired by Dubai Autodrome and Spa-Francorchamps.
- **GT3 LED Shift Array:** Multi-stage green, amber, red, and blue flashing shift lights timed to redline RPM (9,500 RPM).
- **Comprehensive Live Telemetry:** Digital KM/H, G-Force gravity meter, Turbo Boost PSI/Bar, 4-wheel tire thermals & pressures, and Nitrous charge gauge.

### 2. 🏎️ Official AK Racing Demo Car (Interactive 3D WebGL Machine)
- **Authentic GT3 Cup Aerodynamics:** Detailed widebody chassis, swan-neck carbon rear wing, front aero canards, yellow matrix endurance headlights, and BBS multi-spoke racing wheels.
- **Dual Exhaust Active Flame Throwers:** Real-time 3D particle fire streams reacting dynamically to throttle load, launch control, and gear shift crackles.
- **Interactive Burnout Station:** High-density tire smoke clouds and glowing Brembo carbon-ceramic brake discs.
- **360° Orbit Camera & Presets:** Switch instantly between 3/4 Hero view, Exhaust Flame Cam, Driver Cockpit POV, Side Profile, and Aero Top view.
- **Livery Selector:** Choose between *AK Stealth Carbon*, *Dubai 24H Gold*, *Spa Francorchamps Cyan*, and *Monza Redline*.

### 3. 🔊 Procedural GT3 Engine Sound Synthesizer (Web Audio API)
- **Zero-Dependency Acoustic Engine:** 100% synthesized in real-time in the browser with 0 external audio file download delays or broken links.
- **Starter Motor Cranking & Ignition:** Electric starter whir followed by engine catch.
- **Multi-Harmonic Cylinder Firings:** Rich flat-6 / V8 screaming engine howl scaling smoothly from 850 RPM idle to 9,500 RPM redline.
- **Straight-Cut Gearbox Whine:** Distinctive high-pitch dog-ring transmission whine scaling with wheel velocity.
- **Turbo Spool & "Stututu" Blow-Off Valve:** Whistling boost and pressure dump flutter on throttle lift.
- **Exhaust Backfires & Anti-Lag Crackles:** High-impact pops and gunshots timed with visual exhaust flames.
- **Sound Profile Selector:** Switch between *Porsche 992 GT3 Flat-6*, *V8 Twin-Turbo*, and *V10 9,500 RPM Screamer*.

## 🎮 Interactive Controls & Keyboard Shortcuts

| Control | Action |
| :--- | :--- |
| `W` / `Space` / `Up Arrow` | **Throttle / Accelerate** (Rev Engine & Fire Exhaust Flames) |
| `S` / `Down Arrow` | **Brake / Decelerate** (Glows Carbon-Ceramic Rotors) |
| `E` | **Paddle Shift UP** (Triggers Shift Backfire & Flame) |
| `Q` | **Paddle Shift DOWN** (Engine Braking) |
| `N` | **Nitrous Boost** (Cyan Plasma Flame Surge) |
| `L` | **Launch Control** (5,500 RPM Rev-Limit Hold & Dump) |
| `B` | **Burnout Mode** (Tire Smoke & Continuous Flames) |
| `I` | **Engine Start / Stop Ignition** |
| `Mouse Drag` | **Orbit Car 360° in 3D Viewport** |
| `Mouse Scroll` | **Zoom In / Out on 3D Car** |

## 🚀 How to Run Locally

You can launch this project locally using either **Node.js** or **Python**:

### Option A: Using Node.js
```bash
# In the project directory:
npm start
```

### Option B: Using Python 3
```bash
# In the project directory:
python -m http.server 3000
```
Then open your browser and navigate to: **`http://localhost:3000`**

### Option C: Direct Double-Click
Simply open `index.html` directly in any modern browser (Chrome, Edge, Safari, Firefox, Opera).
